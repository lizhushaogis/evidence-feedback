循证 · 大班课主观题的可举证批改

精简 PRD v2 / 2026-11-26 / 交付：PRD、ReAct交互Demo、Skills规程、半页取舍说明

实现更新：现已增加DeepSeek真实后端版本，支持真实模型工具决策、技能加载、引用校验、语义复核、视觉转录与补证恢复，入口live.html，本机运行4174端口。下文关于“预设策略、未接模型”的说明专指GitHub Pages上的v2模拟原型。真实版验收与已发现的语义问题见docs/live-validation.md；运行见docs/live-setup.md。真实模型已跑通不代表已达到后文拟定质量指标。

1. 需求：批完之后，教师能否为每一分负责

目标用户是150人专业基础课的课程负责人，带3名助教批改每份3道简答、论述题。教师负责标准、口径与最终结果；助教需要知道何时升级；学生需要知道失分依据与改进方式。P0限定平时形成性主观题，不独立决定考试成绩或奖学金资格。

用户提供的场景测算：150份×每份6分钟=900分钟，即15小时。“每份”已含3题，不能再乘3。时间只是表面成本，更强的痛点是：批完后面对“为什么扣分”“别的助教为何给得高”时，无法把分数追回原文、标准与裁决记录。

待验证的应对及后果：只给分不写评语→学生不知怎样改；抽批三分之一→覆盖不足；完全交给助教→教师难发现标准漂移。用户提出的反馈延迟2–3周、同卷分差超过10分、“只剩Excel”作为访谈线索，尚非已证实统计。Demo中助教11/17分分歧为虚构示例，不能与这些数字混用。

时刻/角色真正担心什么现有工具缺口产品交付
负责人定标准标准答案未覆盖合理异解Rubric与具体答卷脱节版本化量规、锚卷与负责人裁决
助教逐题批阅这句话算不算答到点Excel留分，聊天讨论难追溯评分点对应原文，跨档争议升级
负责人抽检抽过几份不代表全班口径一致难找最高风险卷缺证、分歧、边界分优先；高把握样本也抽检
学生收到结果泛泛评语无法解释失分不知道怎样行动哪句话触发哪个标准，缺什么、怎样改
学生申诉同题不同标准，要求复评原件、规则和修改历史分散冻结证据包；允许复核改判，而非替机器辩护

成绩可能关联保研、评优、奖学金，作为需核实的风险背景，不据此自动决定学生权益。不能把“高校缺乏阅卷保障”写成普遍事实：Warwick的高校评价原则明确提到双评、抽评与考核委员会。应验证的是部分大班课落实这些保障的成本。

证据分层：Jisc支持高校评价负担与共享评语的一致性价值；Holt等（2024）单校研究支持反馈期望与工时的张力。这些材料不直接证明国内150人课程的时长、分差、申诉率与购买意愿。“可举证”切口是资料与用户场景形成的产品推论。

验证计划：访谈6名负责人、4名助教、6名近期申请过复核的学生；观察3次同卷独立批阅，经授权抽取30份争议或边界卷。核对耗时、分差原因、依据存储位置、一次申诉调证时间、教师信任什么证据。如果主因是题目或量规问题，先校准标准，不能用自动评分掩盖问题。

2. 产品承诺与Agent必要性

承诺：每个建议分数可追到题目、量规版本、原文证据与教师裁决，缺证时明确停止。证据链帮助核验，不等于机器保证公平或正确。

单次LLM可以生成分数，却不能独立可靠维护跨卷口径、核验引用、等待补证、恢复任务与冻结版本。这里采用ReAct：理解目标与当前观察→决策选技能和工具→调用→观察结果→更新状态再决定。正常答案走校准和校验；缺证改用修复技能，失败后等待人工；新证据到达后恢复。不能通过反复采样凑一致。

Demo是带状态的ReAct模拟器：决策与语义评分由预设策略代替模型；白名单工具调用、结构化观察、条件分支、引用存在性检查、预算停止与暂停恢复真实执行。不是生产LLM Agent，也未使用Dify。Skill是任务规程+工具集合+权限与停止条件，不是Agent成立的唯一必要条件。详见Agent机制文档。

P0：单课程、单量规版本、匿名答卷；评分点证据；锚卷比对与分歧升级；改分、改评语、接管；证据包与批次门禁；审计导出。Demo只演示3份答题片段、R2单维度，未实现150人×3题完整批次。

P1：真实PDF/OCR/LMS、多题多维量规、多人双评、校准后局部重跑、学生申诉工单、评分漂移监测。非目标：作弊判罚、自动登分、自动处分和自动决定保研奖学金；同一个模型多次采样不算独立双评。

3. 三类输入与归一

类别理想输入残缺输入统一处理与停止条件
题目与依据题号、Rubric分档、教师确认锚卷只有参考答案、标准冲突、合理异解未覆盖待确认草案与版本；不自造扣分规则，冲突转负责人
学生答卷有编号、题号页码的可提取文本扫描模糊、漏题、跨页、重名文件匿名题目片段与原文锚点；缺失不等于答错，局部重读后补证
现有评分与补证助教逐题分数、锚卷裁决、核对过的原文只有Excel总分、缺备注、口头标准标记来源版本；不从总分倒推扣分点，不凭姓名猜身份

共同结构：batch_id、submission_id、question_id、rubric_version、anchor_version、original_hash、evidence_spans、tool_observations、suggested_score、risk_flags、teacher_decision、revision_history、export_version。保留原件，补证单独记录；标准修改后旧判断失效。Demo支持真实TXT和粘贴，但自定义文本转人工，不套用固定评分。

5. 端到端链路与责任

负责人确认标准→导入答卷→启动可举证评分循环→取证/重读/锚卷比对/约束校验→草稿与风险→教师核验、补证或接管→逐份确认→证据包→导出。申诉时按编号与冻结版本调取原文和决议；P1若改判影响同类答案，提示重查同类卷。

异常闭环：定位返回模糊→下一轮选择重读→失败→请求人工并暂停→教师补充新观察→恢复后选择锚卷比对与校验→Demo因无模型，补证后评分仍留给教师→确认交付。

AI提出可检查的建议、暴露不确定；教师制定标准、判断异解、裁决争议与确认最终结果；规则系统执行权限、版本、停止和导出门禁。附件指令不构成工具授权。展示行动摘要与工具结果，不展示模型私有思维链。

6. 异常与边界

触发条件系统行为兜底与恢复
量规缺失、冲突或合理异解未覆盖不自造标准，停在校准负责人补规则版本化并检查同类卷
量规修改旧建议失效生产局部重跑，Demo转人工
模糊、缺页、识别失败取证失败→重读一次→请求人工补证恢复或接管，不因缺证扣分
助教跨档分歧保留量规解释差异，不平均负责人裁决，P1重查同类卷
引用不存在拦截证据包重取证一次，仍失败转人工
分数越界、版本错误约束校验失败修复输出，失败交教师
工具异常、模型超时留存失败步骤与完成状态生产最多两次技术重试；超限人工
十轮仍不满足交付预算停止，不再自调用人工接管，禁止无限循环
学生正文提示注入只作原文，不获得执行权限白名单与schema；真实模型仍需防注入评测
身份不明、重复卷不猜身份，哈希去重、禁止发布人工映射或选定版本
自定义文本或新标准无模型适配，不输出伪评分调人工技能，保留空分数
改动已确认反馈撤销该份确认，阻断批次重新核验并确认，记录变化事件
学生质疑评分点查原件和冻结依据负责人复核可改判，P1第二教师仲裁
刷新或中断本地存储循环与人工草稿恢复状态继续，生产需服务端持久化与幂等
隐私或越权生产课程隔离、身份正文分离、最小权限撤销访问并审计；Demo仅用虚构或脱敏材料

生产需禁止以学生数据训练模型、传输存储加密、保留期按学校申诉规则确认。Demo的localStorage与JSON不是防篡改存证，未实现模型、OCR、LMS、真实锚卷、哈希审计、多人协同与申诉服务。

7. 评测与指标

数值是试点目标，不是实测结果。主指标由“批得快”转为“可核验、可复核”。

类型定义初步门槛
业务举证完整率：有量规版本、原文、理由与教师确认的交付评分点/全部交付评分点100%，缺项不交付
业务申诉调证耗时：收到评分点质疑至定位完整依据的人工时间比Excel基线中位数减少50%，配对实验
业务实质改判率：盲审需改分档条目/抽检条目不高于人工基线，另报严重错评；不压制合理申诉
业务总人工时间：标准校准、核验、修改、接管与复核时间比基线减少30%，不只计生成时间
AI引用逐字存在率与语义支持准确率分开统计≥99%、≥98%，严重捏造0
AI与课程教师仲裁一致：MAE、分档一致、加权Kappa、分差≤2/20比例分差≤2比例≥90%，按课程题型分层
AI高风险召回：标记出的真实缺证/分歧样本占比≥95%，单列漏判，不盲目降低转人工率
AI约束满足率：版本、分数、引用、权限全通过/输出数≥99%，未确认发布0
Agent正确选工具、补证恢复、预算内终止、错误交付专项轨迹集，预算内终止100%、错误交付0
过程一次可用率、实质修改率、转人工率一次可用目标≥70%；按原因分层，接管不一概视为失败

评测集：至少300份授权脱敏答题，跨3门课程、多题目与学期；另做60条压力轨迹（模糊、缺页、异解、标准冲突、注入、工具失败、预算）。合成异常单独报告。2名课程教师独立标证据跨度、分档、分数、人工风险与可接受工具路径，第三人仲裁；先30条校准口径。允许多条合理工具路线，不能只匹配固定次序。

按课程/题目/学期分组切60%开发、20%验证、20%锁定测试，同卷改写不跨集，新学期外部验证。记录模型、量规、技能版本；阈值提示词只调开发验证集，限制测试集调用。教师点通过不直接当金标准，模型自评不替代人工。

灰度：2名教师影子运行，不改成绩；达门槛后10%授权批次，再30%。始终逐份人工确认，高低分、边界卷和高把握卷都抽检。严重错引、未确认发布或高风险漏判立即停新批次回退版本，人工继续。每周盲审改判原因、补证、助教口径冲突、工具失败与耗时，回流开发集，保持测试集锁定。

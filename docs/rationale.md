# 选题理由与关键取舍（半页）

我选择“高校形成性文字作业的循证反馈”，而不是覆盖备课、考试和教务的全能助手。课程教师每次批阅都需要把学生原文、教学要求和反馈联系起来；重复劳动集中，但教学判断仍需教师承担。Jisc 的高校评价指南及 Holt 等人（2024）的高校研究为批阅负担和反馈期望之间的矛盾提供了依据。中国高校的具体频率、付费意愿和效率收益尚未验证，因此把用户规模与收益写作假设，不虚构访谈。

产品最重要的设计不是生成更长的评语，而是减少教师核验成本：原文与量规同屏、每条建议都有定位、置信度附风险解释、分数与措辞可修改、低把握时主动停下。教师的“接管”是正常完成方式，不是失败按钮。即便扫描件看不清，也不能自动判学生答错。

第一版主动舍弃自动登分、作弊判断、多课程协作和多模态作业，换取一条可完整演示且可审计的主链路。Agent 负责跨文档取证、工具编排、规则检查与等待确认，规则系统承担权限和导出门禁；教师保留标准制定和最终反馈责任。Demo 使用虚构数据，不接真实模型，不用预设置信度冒充准确率；自定义输入转人工，避免展示与输入无关的“AI 结果”。

下一步先观察教师真实批阅，验证核验证据是否比重写评语更快，再通过锁定测试集和影子试点决定是否值得继续投入。成功应表现为教师用更少时间给出有依据、可行动的反馈，而不只是模型吐字更快。

三分钟演示与验收

正常链路（约 90 秒）

1. 工作台说明角色与任务：形成性反馈，演示数据，不自动发成绩。

2. 点“新建批阅任务”，看三类输入与量规，勾选确认，开始执行。

3. 展示四步日志：规范化、量规取证、证据核对、约束检查。可中止回输入。

4. 进入复核，左边看原文与标准，右边看依据和置信度。把 S-017 的反馈补充一句建议，填写核对勾选并确认。

5. 核对 S-024 后确认。全部完成后查看结果，下载 CSV 与 JSON，展示依据和日志随结果保留。

异常链路（约 90 秒）

1. 回到工作台，点“体验低置信度与人工接管”。

2. 执行后先确认两份正常作业。到 S-031，看到扫描模糊、48% 演示置信度和空分数。

3. 直接确认会被阻止，说明“证据不足不扣分”。

4. 路线 A：输入自己核对过的证据，保存补证后人工评价。路线 B：点击“人工接管”。

5. 填写 0–20 整数分数和可行动反馈，核对并确认，再导出。日志记录接管与确认。

额外可验证细节

- 未确认量规不能开始；空标题 / 空量规有提示。

- 自定义文本 / TXT 导入不复用内置评分，进入人工复核。

- 改量规后旧建议失效，转人工；不伪装模型重新执行。

- 未确认全部作业不能进入结果；无反馈或越界分数不能确认。

- 已确认后修改内容并保存会撤销确认；刷新可恢复草稿。

- CSV 带 UTF-8 BOM、正确转义并防公式注入；支持导出审计 JSON。

- 手机窄屏为单列布局，按钮有焦点样式。

实现边界

网站无依赖，HTML + CSS + JavaScript，GitHub Pages 静态托管。执行进度、检索、置信度为可解释的固定样例；自定义内容不接模型。PDF / DOCX / OCR、真实身份、LMS、权限和服务端存储均为 PRD 规划。不要把真实学生隐私输入此公开原型。草稿只在当前浏览器 localStorage，导出文件由浏览器下载。

三分钟演示：分数背后的证据链

开场20秒

这是150人大班课程的场景假设，每份3道主观题。痛点是批完后能否回答为什么给这个分。Demo精简为3份答题片段、一个评分维度。

正常与分歧60秒

1. 新建，阅读并确认量规，开始执行。

2. 点执行下一轮：读标准；再一次：取原文。每轮显示感知、决策摘要、Skill、工具与观察。

3. 自动运行至停止点，当前作业就绪后停止；切换S-024再自动执行，观察锚卷比对返回助教11/17分分歧，系统不平均而是保留争议和待核15分草稿。

4. 教师复核原文、量规、分档理由与轨迹。改分改评语、核对确认。确认相当于负责人对本次分歧作出裁决。

异常60秒

1. 工作台点体验缺证→修复→补证循环，开始后切S-031。

2. 自动运行：取证模糊→下一轮改选重读→失败→请求人工，停下。

3. 填写核对过的补证，提交新观察并继续循环。再自动运行，下一步变为锚卷比对与引用校验，不再重读。

4. 进入教师复核，因Demo没接模型，新证据不生成评分，教师填分数与评语。也可直接接管，保留缺证风险。

收尾20秒

确认所有作业后导出CSV反馈与JSON证据包。JSON含原文、量规、补证、工具观察、风险和教师决议；供申诉复核调证，允许改判。完整学生申诉工单是P1。

验收

正常、缺证、自定义输入选择不同路径；补证会改变后续工具。自动运行只处理当前作业，切换后再执行其他作业。全批仍有运行项时批次入口禁用。未确认标准不能开始，低把握不能直接确认；分数须0–20整数且评语非空。改动后撤销确认；未全确认不能交付。Agent Skills入口可读四项技能规程。刷新后可恢复草稿与循环状态。

技术边界：预设策略模拟模型决策；工具、分支和约束本地执行，未接Dify、模型或OCR。所有内置样例和置信度为演示值，JSON不是防篡改审计。
